会话 icon · 4 个动画方案

鼠标 hover / 持续播放 / 点击触发。挑一个喜欢的方向，我直接接到 nav tab 的 conversation icon 上。

A · 打字机三点

圆点轮流跳起，像 iMessage 打字指示器。持续播放，无 hover 触发。

持续

B · 气泡呼吸

整个气泡 scale 1 ↔ 1.06 循环，柔和。持续播放。

持续 · 柔和

C · 描边出现

线条从无到有「画」出来。hover 触发，不打扰默认状态。

hover

D · 尾巴抖动

左下小尾巴每 3.6s 抖一下，像气泡在「说话」。持续播放，克制不抢眼。

持续 · 克制

hover 到 C 卡片上触发描边动画。其他 3 个持续循环。
