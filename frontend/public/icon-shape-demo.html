会话 icon · 5 种形状风格

换了气泡的形状。Lucide / Heroicons / 自定义 各种风格。挑一个用 — 后续可以再套前面的动画（A 打字 / B 呼吸 / C 描边 / D 尾巴抖）。

1 · 双泡左右

两个对话气泡左右对称，Heroicons 风格。表达「对话 / 来回」。

heroicons

2 · 重叠方块

两个圆角方块一前一后重叠，Lucide 风格。极简现代。

lucide

3 · 单泡 + 三点

一个圆角气泡 + 3 个对话点，iMessage / Slack 风格。最像「正在打字」。

iMessage

4 · 泪滴气泡

圆润水滴形气泡 + 文字行。Phosphor 风格，柔和。

phosphor

5 · 极简三横线

没有气泡框，只有 3 条横线 + 一个小点。Tabler 风格，最克制。

tabler
